适用于 RPG Maker MV / MZ 的**游戏内修改器与 AI 翻译工具**。

Grimoire 本身即是一个 RPG Maker 插件，因此 PC（NW.js）、Android WebView、桌面浏览器
三种环境共用同一份代码，无需外部进程、无需注入、无需 root 权限。

安装后，画面角落会出现一个可拖动的齿轮按钮，点击即可打开面板。

```
Grimoire.js      单文件插件，152 KB，无任何依赖
一键安装.bat      一键安装器，10 KB
```

## 安装

下载仓库中的以下两个文件：

```
Grimoire.js
一键安装.bat
```

将两者放在同一目录下，置于游戏目录内或游戏目录的同级位置，然后**双击 bat**。
也可以将游戏目录直接拖放至 bat 上，支持一次拖放多个。

安装器会自动定位游戏、备份 `plugins.js`，并将插件登记在插件列表末尾。对已安装过的
游戏再次运行时，会询问执行「更新」还是「卸载」。若附近未找到游戏，则弹出目录选择对话框。

游戏查找顺序：命令行参数 → bat 所在目录及其上三层 → 下一层与同级目录 → 目录选择对话框。
MV 的 `www/` 结构与 MZ 的扁平结构均可识别。

<details>
<summary>手动安装</summary>

将 `Grimoire.js` 复制到 `js/plugins/`（MV 为 `www/js/plugins/`），
并在 `js/plugins.js` 的数组**末尾**追加一条：

```json
{"name":"Grimoire","status":true,"description":"","parameters":{}}
```

必须置于列表末尾，以保证其钩子能够包裹其他插件。修改前请备份 `plugins.js`。

</details>

**卸载**：再次运行 bat 并选择「卸载」；或将 `js/plugins.js.grimoire-bak` 覆盖回
`plugins.js`，该文件为安装前的原始备份。

## 功能

面板共 12 页。默认快捷键 **Insert**（可在插件参数中修改），移动端通过悬浮按钮呼出。

| 页 | 内容 |
|---|---|
| 角色 | 等级、经验、HP / MP / TP、八项能力值加成、职业切换、入队与离队；技能全部习得 / 单个习得；状态增删 |
| 增益 | 无敌、秒杀、技能不消耗 MP、穿墙、不遇敌、始终冲刺、对话即时显示、1~8 倍速、经验 / 金钱倍率 |
| 道具 | 金钱修改；道具 / 武器 / 防具搜索、直接填写数量或 +1 / -1、整列表批量设为 99 或清空；**支持逐项锁定数量** |
| 开关 | 搜索、逐项切换、整列表批量开关；**支持逐项锁定** |
| 变量 | 搜索、修改取值（数字与字符串均支持）；**支持逐项锁定** |
| 战斗 | 强制胜利 / 逃跑 / 中断 / 失败；我方全体恢复；逐个修改敌人 HP 或直接击杀 |
| 地图 | 显示当前坐标；本图坐标传送；传送至任意地图并自动寻找可通行落点 |
| 事件 | 公共事件列表与执行 |
| 存档 | 各槽位存档 / 读档；**存档文本的导出与导入** |
| 翻译 | **对接 AI 模型，全量翻译游戏文本**，详见下一节 |
| 系统 | 模拟按键 / 直接打开菜单 / 存读档 / 设置 / 调试等场景；解除菜单、存档、整队、遇敌的禁用限制；八项卡死修复 |
| 设置 | 面板字号、按钮透明度、游戏内字号微调、重置悬浮窗位置 |

**锁定**：开关、变量、道具的每一行右侧均设有「解 / 锁」按钮。锁定后，游戏内对该槽位的
任何写入都会被丢弃，取值保持固定，仅能通过面板修改。读取存档与开始新游戏后会自动
重新施加。

**存档导出**在 Android 环境下尤为重要：移动端存档保存于 WebView 的 IndexedDB 中，
无 root 权限无法取出，清除一次应用数据即全部丢失。该页可将存档导出为文本，复制到
其他设备后导入。

## AI 翻译

支持任何 **OpenAI 格式**的接口：官方 API、各类中转服务，以及本地部署的
ollama / LM Studio / vLLM。

使用流程：填写 API 地址与密钥 → 获取模型 → 扫描文本 → 开始翻译 → 重启游戏。

### 仅替换内存数据，不修改游戏文件

译文单独保存为词典文件，游戏自身的 `data/*.json` 不作任何改动——替换发生在数据
载入内存之后。词典存在时自动加载。

| 环境 | 词典位置 |
|---|---|
| PC（NW.js） | `<游戏目录>/grimoire/dict-<游戏标题>.json`，纯 JSON，可手动编辑与分享 |
| Android / 浏览器 | IndexedDB |

### 需手动配置的仅三项

API 地址、API 密钥、模型，其余均为自动处理：

- **扫描范围**八项默认全部启用，各项分别自动定位来源：数据库、系统术语、公共事件、
  战斗事件、地图事件、插件参数、插件源码、文本容器
- **源语种自动识别**：依据字形判别日 / 中 / 英 / 韩 / 俄，避免以日语配置翻译英文游戏
- **屏幕记录**默认启用：记录屏幕上出现过而词典中缺失的文本，在下次扫描时一并翻译

### 三项操作

| 按钮 | 说明 |
|---|---|
| 开始翻译 | 对扫描结果执行全量翻译，完成后整体覆盖旧词典（旧词典自动保留一份 `.bak`） |
| 修复翻译 | 仅重新翻译失败条目，结果直接并入现有词典 |
| 深度润化 | 在**同一会话**中对已有译文整体复核：统一术语、纠正误译 |

失败记录（条目及其失败原因）与词典一同保存，**游戏重启后依然保留**。

### 覆盖范围的已知限制

- **图片中的文字**：标题、按钮、说明图等属于美术资源
- **插件动态拼接的字符串**：如 `"【" + 名字 + "】"`，绘制到屏幕上的完整语句无法与
  词典匹配
- 备注栏、脚本指令、插件指令、开关与变量名称为**有意跳过**，这些内容由插件读取
- 文本容器扫描**仅在 PC 端可用**（浏览器环境无法枚举目录）；移动端可先在 PC 端完成
  翻译，再通过「导出 / 导入词典」迁移

### 费用

翻译按模型的输入与输出计费。开始前请先确认扫描得到的字数，大型游戏达到五六十万字
属于常见情况。建议先仅勾选「系统术语」进行小规模试验，确认效果后再执行全量翻译。

## 兼容性

| 环境 | 引擎 | 状态 |
|---|---|---|
| PC（NW.js） | MV / MZ | 实机验证：词典写入文件、启动时自动加载 |
| Android WebView | MZ | 真机触摸操作全部通过 |
| 桌面浏览器 | MV 1.5.1 / 1.6.1 / MZ 1.8.0 | 12 页全部渲染正常、钩子全部生效、无报错 |

**运行环境要求：Chromium 55 及以上**（NW.js 0.19+）。MV 1.5 / 1.6 自带的 NW.js 0.29
为 Chromium 65，满足要求。低于该版本时，`async/await`（55）与箭头函数（45）无法解析，
插件将无法加载，且**不会有任何提示**。

MV / MZ 的差异集中于单独一层适配层，功能代码不区分版本。样式表有意避开了 `inset`、
`min()`、flex `gap`、`:focus-visible` 等新特性——它们在旧版 NW.js 上会静默失效，
导致布局异常。

**与其他插件共存**：界面采用 DOM 浮层实现，不涉及引擎的 `Window_Base`，因此不会与
改写窗口系统的插件产生冲突。面板内的点击事件在浮层根节点处终止，不会透传至游戏。

## 注意事项

- 修改数值实质上是在改动存档数据，**操作前请先存档**。
- 「执行公共事件」会实际执行一遍事件指令。部分事件供系统内部调用，单独执行可能导致
  剧情标记错乱。
- 「打开场景」会绕过游戏的禁用判定。部分游戏在特定剧情中禁用菜单有其设计原因，
  如出现卡死请使用「卡死修复」。
- 能力值修改的是**加成值**，叠加于职业成长曲线与装备加成之上。
- API 密钥以明文保存于 localStorage 中。
